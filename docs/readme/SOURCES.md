# README 素材与核验

## 视觉方向

延续项目原有的深橄榄绿、暖纸面、宋体和绿色台灯。先展示真实写作体验，再介绍 Blender 的分层制作。标题、安装命令和功能说明保留为可搜索、可复制的 Markdown。

主视觉右侧是当前网页的真实写作态截图；仅在本轮草稿输入示例文字，未改动产品布局或机械状态。截图按打字机容器裁切，排除浏览器扩展浮层。没有生成虚构的产品界面、模型或用户数据。

## 采集与检查

2026-11-24，以应用源码 `20d5fdacb4446b1f7ae2cf2154cd1137e131ceee` 运行本地静态页面，通过 Ego 在独占任务空间执行真实操作。

- 点击页面自带的「看看打字效果」，逐字写入英文、换行与中文。没有用终态图片模拟打字过程。
- 移动方向键后，文字保持不变，字头位置变化；恢复到文末再收起键盘。
- 关灯后状态变为关闭，再重新打开；点击「完成」进入阅读态。
- 导出按钮显示实际成功反馈，单独下载的 UTF-8 文本与示例内容完全一致；浏览器草稿读回一致。
- 仅采集本轮示例，未读取或清理用户的正式站点草稿。

最终 MP4 使用 210 张按实际时间戳记录的网页画面，采集约 22.57 秒，实际约 9.3 帧/秒；相邻帧最大间隔 165 毫秒，逐字阶段最大间隔 155 毫秒。编码为 30 fps 方便播放，不表示原生 30 fps 录屏。GIF 从这份通过检查的成片截取。

首轮采集曾因浏览器长等待阻塞取帧，缺失逐字过程；该版本已弃用，没有收入本目录。最终成片检查全时段抽帧、媒体信息和完整解码，另核对逐字阶段的帧间隔。

本轮未修改应用源码、重新发布网站，或验收手机系统的真实输入法。既有页面与发布记录见 [DEPLOYMENT.md](../../DEPLOYMENT.md)。
